    Задание 13: Количество программ исполнителя¶

    Что стоит знать перед выполнением¶

    Команда - некое правило, которое превращает текущее число x в новое число, например:

    • «прибавь k
    • «умножь на k;
    • «раздели нацело на k.

    Программа - последовательность данных правил (команд).

    Траектория вычислений - последовательность результатов выполнения каждой команды программы. Стартовое число в траекторию не входит, а последнее число траектории - это результат работы всей программы.

    Пример: Команды: - 1: прибавить 6 - 2: умножить на 4 - 3: прибавить 7

    Программа: 132

    Исходное число: 3 Траектория: 9, 16, 64 (3 + 6 = 9, 9 + 7 = 16, 16 * 4 = 64).

    Если сказано, что траектория содержит число n значит: где-то в этой последовательности результатов есть n, причём n может совпадать и с конечным числом - оно тоже часть траектории.

    Задача 1¶

    Источник

    ФИПИ · уровень: средний

    Исполнитель Кантата преобразует число на экране.

    У исполнителя есть три команды, которым присвоены номера:

    Прибавить 1. Умножить на 2. Умножить на 3. Первая команда увеличивает число на экране на 1, вторая умножает его на 2, третья умножает его на 3. Программа для исполнителя Кантата - это последовательность команд.

    Сколько существует программ, для которых при исходном числе 5 результатом является число 43 и при этом траектория вычислений содержит число 9, но не содержит число 27?

    Траектория вычислений программы - это последовательность результатов выполнения всех команд программы. Например, для программы 123 при исходном числе 7 траектория будет состоять из чисел 8, 16, 48.

    Решение¶

    from functools import lru_cache

@lru_cache(None)
def f(n, target, bad=()):
    if n in bad or n > target:
        return 0
    if n == target:
        return 1
    return f(n + 1, target, bad) + f(n * 2, target, bad) + f(n * 3, target, bad)

print(f(5, 9) * f(9, 43, (27,)))

    Что делает код:

    • @lru_cache - декоратор, который запоминает результаты вызовов функции, чтобы не считать одно и то же дважды.
    • def f(n, target, bad=()): - объявляем функцию: n - исходное число, target - конечное, bad - кортеж чисел, которые траектория не должна содержать.
    • if n in bad or n > target - если число находится в списке «исключённых» или больше конечного - возвращаем ноль, такой программы нет.
    • if n == target - если n - конечное число, то возвращаем 1, значит такая программа есть.

    • return f(n + 1, target, bad) + f(n * 2, target, bad) + f(n * 3, target, bad) - если ни одно из условий выше не сработало, значит мы ещё не дошли до цели и не попали в тупик. Тогда пробуем все три команды по очереди и складываем количество программ для каждой:

      • f(n + 1, target, bad) - сколько программ получится, если первой выполнить команду «прибавить 1» (число станет n + 1);
      • f(n * 2, target, bad) - сколько программ получится, если первой выполнить команду «умножить на 2» (число станет n * 2);
      • f(n * 3, target, bad) - сколько программ получится, если первой выполнить команду «умножить на 3» (число станет n * 3).

      Каждое слагаемое - это рекурсивный вызов той же функции, но уже от нового числа. Функция снова спросит: «а сколько программ ведёт из этого нового числа в цель?» - и так до тех пор, пока не упрётся в цель (вернёт 1) или в тупик (вернёт 0).

      Поскольку команды взаимоисключающие (первой может быть только одна из трёх), общее число программ = сумма количеств программ для каждого варианта первого хода. Именно поэтому здесь стоит +, а не *. - print(f(5, 9) * f(9, 43, (27,))) - для того, чтобы найти, сколько программ содержат число 9, сначала ищем количество программ, которые ведут от 5 к 9 и умножаем на количество программ, которые ведут от 9 к 43, но на пути может встретиться 27, а так как его в траектории быть не должно, передаем кортеж (27,). Если написать без запятой, то передастся целочисленное значение, которое просто заключено в скобки, а не кортеж.

    Ответ

    19
