# informatika-ege-guide

Гайд создан **для личного пользования** - для повторения информации, необходимой для сдачи ЕГЭ по информатике.

## Сайт

**[https://x1e7.github.io/informatika-ege-guide/](https://x1e7.github.io/informatika-ege-guide/)**

Опубликовано на GitHub Pages **исключительно для удобного доступа с любого своего устройства**.

## О гайде

- Гайд **не является учебным материалом** и не создан с целью кого-то научить.
- Материал собран **на основе собственных знаний** и информации, найденной в открытых источниках.
- Структура и примеры - результат **личной подготовки** к экзамену.
- Публикация **не подразумевает** образовательной ценности для других - это просто «конспекты» в облаке.

## Локальный запуск

```bash
pip install -r requirements.txt
mkdocs serve
```
