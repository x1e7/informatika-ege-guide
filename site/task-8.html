    Задание 8: Перебор слов и системы счисления¶

    Что стоит знать перед выполнением¶

    • Функция product() из модуля itertools
    • Индексы в Python
    • Метод join()

    Задача 1¶

    Ольга составляет таблицу кодовых слов для передачи сообщений, каждому сообщению соответствует своё кодовое слово. В качестве кодовых слов Ольга использует 4-буквенные слова, в которых есть только буквы A, B, C, D, E, X, причём буква X появляется ровно 1 раз и только на первом или последнем месте. Каждая из других допустимых букв может встречаться в кодовом слове любое количество раз или не встречаться совсем. Сколько различных кодовых слов может использовать Ольга?

    Решение¶

    from itertools import product

words = product('ABCDEX', repeat=4)   # repeat=4 - длина слова
cnt = 0

for w in words:
    word = ''.join(w)                 # составляем слово из кортежа
    if word.count('X') == 1 and (word[0] == 'X' or word[-1] == 'X'):
        cnt += 1

print(cnt)

    Что делает код:

    • product('ABCDEX', repeat=4) - генерирует все возможные 4-буквенные комбинации из 6 букв (6⁴ = 1296 вариантов).
    • ''.join(w) - склеивает кортеж символов в строку.
    • word.count('X') == 1 - проверяет, что буква X встречается ровно один раз.
    • word[0] == 'X' or word[-1] == 'X' - проверяет, что X стоит на первом или последнем месте.

    Ответ

    250

    Задача 2¶

    Все четырёхбуквенные слова, составленные из букв А, Л, Г, О, Р, И, Т, М, записаны в алфавитном порядке и пронумерованы, начиная с 1. Начало списка выглядит так:

    1. АААА
2. АААГ
3. АААИ
4. АААЛ
5. АААМ
6. АААО
7. АААР
8. АААТ
9. ААГА
…

    Под каким номером в списке идёт первое слово, которое начинается с букв ГО?

    Решение¶

    Буквы распределяем по алфавиту. Проходим все комбинации в лексикографическом порядке, увеличивая счётчик k. Как только встретили слово, начинающееся на ГО - выводим номер.

    a = {0: "А", 1: "Г", 2: "И", 3: "Л", 4: "М", 5: "О", 6: "Р", 7: "Т"}
k = 0

for i in range(0, len(a)):          # 1-е число
    for j in range(0, len(a)):      # 2-е число
        for g in range(0, len(a)):  # 3-е число
            for m in range(0, len(a)):  # 4-е число
                k += 1
                if a[i] == 'Г' and a[j] == 'О':
                    print(k)         # Возьмём первое число, которое выдаст программа

    Как это работает:

    • a - словарь, где ключ - номер буквы в алфавите, значение - сама буква.
    • Вложенные циклы перебирают все комбинации в правильном лексикографическом порядке: сначала меняется последний индекс m, потом g, потом j, потом i.
    • k - счётчик, увеличивается на каждой итерации внутреннего цикла.
    • Как только первые две буквы - Г и О, выводим k.

    Почему алфавит именно такой

    Буквы А, Л, Г, О, Р, И, Т, М надо отсортировать по алфавиту: А, Г, И, Л, М, О, Р, Т. Индексы 0..7 соответствуют этому порядку.

    Ответ

    833

    Задача 3¶

    Света составляет 5-буквенные коды из букв С, В, Е, Т, А. Буквы в коде могут повторяться, использовать все буквы не обязательно, но букву С нужно использовать хотя бы один раз. Сколько различных кодов может составить Света?

    Решение¶

    from itertools import product

words = product('света', repeat=5)
cnt = 0

for w in words:
    word = ''.join(w)
    if word.count('с') >= 1:   # 'с' русская буква! Если написать англ., выведет 0
        cnt += 1

print(cnt)

    Что важно:

    • product('света', repeat=5) - все 5-буквенные комбинации из 5 букв (5⁵ = 3125).
    • word.count('с') >= 1 - проверяем, что буква С встречается хотя бы один раз.
    • ⚠️ 'с' - русская буква, не латинская c. Если случайно написать английскую - программа выведет 0.

    Ответ

    2101

    Задача 4¶

    Все 5-буквенные слова, составленные из букв А, К, Р, У, записаны в алфавитном порядке. Вот начало списка:

    1. ААААА
2. ААААК
3. ААААР
4. ААААУ
5. АААКА
……

    Укажите номер первого слова, которое начинается с буквы У.

    Решение¶

    a = {0: "А", 1: "К", 2: "Р", 3: "У"}
k = 0

for i in range(0, len(a)):          # 1-е число
    for j in range(0, len(a)):      # 2-е число
        for g in range(0, len(a)):  # 3-е число
            for m in range(0, len(a)):  # 4-е число
                for n in range(0, len(a)):  # 5-е число
                    k += 1
                    if a[i] == 'У':
                        print(k)     # Возьмём первое число, которое выдаст программа
                        break

    Что происходит:

    • Пять вложенных циклов - по одному на каждую позицию в слове.
    • a[i] == 'У' - первая буква слова равна У. Как только нашли - печатаем номер и выходим из внутреннего цикла.
    • Так как слова идут в лексикографическом порядке, первое слово на У идёт сразу после всех слов на А, К, Р.

    Ответ

    769
