    Задание 19–21: Теория игр¶

    Разбор заданий 19, 20 и 21 ЕГЭ по информатике — теория игр, две кучи, рекурсивный перебор.

    Теория¶

    Типы формулировок¶

    Тип Суть условия Ключевые слова
    Тип А (классический) Петя не выигрывает за 1 ход, но при любом его ходе Ваня выигрывает своим первым ходом. «при любом ходе Пети», «независимо от того, как пойдёт Петя»
    Тип Б (редкий) Петя не выигрывает за 1 ход, но существует такой его ход, после которого Ваня выигрывает. «после неудачного хода Пети», «если Петя ошибётся», «может выиграть»

    Примечание

    В большинстве вариантов ЕГЭ используется Тип А, даже если в условии упоминается «неудачный ход». Всегда ориентируйтесь на точную формулировку из официального задания.

    Логика решения (на примере)¶

    Имеется игровая позиция, характеризуемая целым числом S — текущее количество камней. Начальное значение 1 ≤ S ≤ 125. Игроки (Петя и Ваня) ходят по очереди, первый ход делает Петя.

    Допустимые ходы из позиции S:

    • f₁(S) = S + 2
    • f₂(S) = S + 4
    • f₃(S) = S × 2

    Игра завершается победой текущего игрока, если после его хода количество камней становится S ≥ 125 (порог победы, обозначим W = 125).

    Определение выигрышных и проигрышных позиций¶

    Тип позиции Формальное определение
    Выигрышная за 1 ход (W1) Позиция S, из которой игрок, делающий ход, может непосредственно достичь порога W. Существует хотя бы один ход f(S) ≥ 125.
    Проигрышная при любом ходе (L) Позиция S, из которой все возможные ходы ведут в выигрышные для соперника позиции.

    Алгоритм анализа¶

    В задании 19 требуется найти минимальное S, при котором одновременно выполняются два условия:

    1. Петя не может выиграть за один ход (ни один ход Пети не приводит к S' ≥ 125).
    2. При любом ходе Пети Ваня может выиграть своим первым ходом (после хода Пети в позицию S' Ваня имеет хотя бы один ход, приводящий к S' ≥ 125).

    Пример типа А (W = 125, операции +2, +4, ×2)¶

    Шаг 1. Интервал выигрышных за 1 ход позиций (W1)

    Позиция S выигрышна за 1 ход, если хотя бы одно из значений S+2, S+4, S·2 не меньше 125.

    • Умножение (сильнейшее): 2S ≥ 125 ⇒ S ≥ 62.5 → S ≥ 63
    • Сложение с 4: S+4 ≥ 125 ⇒ S ≥ 121 — покрывается
    • Сложение с 2: S+2 ≥ 125 ⇒ S ≥ 123 — покрывается

    Все позиции S ≥ 63 — выигрышные за 1 ход. Позиции S ≤ 62 не дают немедленной победы.

    Шаг 2. Анализ позиций S ≤ 62

    Нам нужно, чтобы любой ход Пети из S приводил к позиции S' ∈ [63; 124]. При этом Ваня из любой полученной S' должен выиграть за 1 ход, то есть S'·2 ≥ 125 ⇒ S' ≥ 63.

    Шаг 3. Поиск минимального S

    Все три значения после хода Пети должны быть ≥ 63:

    • S + 2 ≥ 63 ⇒ S ≥ 61
    • S + 4 ≥ 63 ⇒ S ≥ 59
    • S × 2 ≥ 63 ⇒ S ≥ 31.5 → S ≥ 32

    Самое сильное ограничение — +2, значит S ≥ 61.

    Проверка S = 61:

    • 61+2 = 63 → Ваня умножает: 126 ≥ 125 ✓
    • 61+4 = 65 → Ваня умножает: 130 ≥ 125 ✓
    • 2×61 = 122 → Ваня умножает: 244 ≥ 125 ✓

    Проверка S = 60: Петя может сходить 60+2 = 62. Из 62 Ваня не выигрывает за 1 ход (62×2 = 124 < 125). Условие нарушено.

    Ответ для типа А

    Минимальное S = 61

    Тип Б: «после неудачного хода Пети»¶

    Условие типа Б

    Петя не может выиграть за один ход. Известно, что Ваня выиграл своим первым ходом после неудачного первого хода Пети. Укажите минимальное значение S, при котором такая ситуация возможна.

    Позиции S ≥ 63 выигрышны за 1 ход, S ≤ 62 — нет.

    Нам нужно минимальное S ≤ 62, при котором хотя бы один ход Пети приводит к S' ∈ [63; 124].

    Условие для умножения: S·2 ≥ 63 ⇒ S ≥ 32.

    Проверка S = 32:

    • 32+2 = 34 (Ваня не выигрывает)
    • 32+4 = 36 (Ваня не выигрывает)
    • 2×32 = 64 → Ваня умножает: 128 ≥ 125 ✓ выигрыш!

    При S = 31 ни один ход не приводит в интервал [63; 124].

    Ответ для типа Б

    Минимальное S = 32

    Важное правило

    Если Петя любым своим ходом создает ситуацию, из которой Ваня выигрывает за 1 ход — это проигрыш Пети.

    Типы заданий¶

    Тип Что происходит На что обратить внимание
    Одна куча, только плюсуем или умножаем Есть куча камней. За ход можно добавить камней или умножить кучу. Кто первый набрал N — победил. Самый частый тип. Всё считается в одну переменную.
    Одна куча, убавляем или делим Кучу можно уменьшать: отнять, поделить. Цель — оставить 1 камень или загнать в тупик. Проверять чётность, делимость.
    Две кучи Две кучи, ходить можно в любую. Победа по сумме. Обычно одну кучу фиксируют — задача сводится к одномерной.

    Одна куча (+ увеличиваем)¶

    Пример 1¶

    Возьмём тот самый пример из теории.

    def f(s, k):
    if s >= 125:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s+2, k-1), f(s+4, k-1), f(s*2, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return all(m)
print(*[s for s in range(1, 125) if f(s, 2)])

    Код с подробным объяснением¶

    def f(s, k):                      # s - камни в куче, k - сколько ходов осталось
    if s >= 125:                  # если игра уже закончилась победой
        return k % 2 == 0         # True, если победил Петя (чётное k), иначе False
    if k == 0:                    # ходы кончились, но победа не достигнута
        return 0                  # значит, ветка невыигрышная
    m = [f(s+2, k-1), f(s+4, k-1), f(s*2, k-1)]
    if (k-1) % 2 == 0:            # если следующий ход Пети
        return any(m)             # Ваня ищет хотя бы один выигрышный ход
    return all(m)                 # Петя должен проиграть при любом ходе

print(*[s for s in range(1, 125) if f(s, 2)])

    Что означают any() и all()¶

    • any(m) — «существует хотя бы один выигрышный ход». Используется для Вани, потому что он сам выбирает, как сходить.
    • all(m) — «все ходы ведут к выигрышу». Используется для Пети в задании 19, потому что он должен проиграть при любом своём выборе.

    В коде для Пети стоит all(m) — это даёт ответ 61. Если заменить на any(m), получим ответ для типа Б: 32.

    Пример 2¶

    Задание: Укажите количество значений S, при которых Петя не может выиграть за один ход, но при любом ходе Пети Ваня может выиграть своим первым ходом.

    def f(s, k):
    if s >= 471:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s+4, k-1), f(s+7, k-1), f(s*4, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return all(m)
print(*[s for s in range(1, 471) if f(s, 2)])

    Ответ

    4

    Одна куча (− уменьшаем)¶

    Пример 1 — демоверсия 2025¶

    Условие: Петя и Ваня, одна куча. Ходы: убрать 2, убрать 5, разделить на 3 (с округлением до меньшего). Игра заканчивается, когда камней становится ≤ 19. Найти минимальное S (S ≥ 20), при котором Петя не выигрывает за 1 ход, но при любом ходе Пети Ваня выигрывает своим первым ходом.

    Разбор вручную¶

    Выигрышная позиция за 1 ход — та, из которой можно сразу попасть в ≤ 19.

    • Убрать 2: S − 2 ≤ 19 → S ≤ 21
    • Убрать 5: S − 5 ≤ 19 → S ≤ 24
    • Разделить на 3: ⌊S/3⌋ ≤ 19 → S ≤ 59

    Сильнейшая операция — деление на 3. Значит, все S от 20 до 59 — выигрышные за 1 ход. А S = 60 уже нет: 60−2=58, 60−5=55, 60/3=20 — все > 19.

    Граница W1 = 60. Нам нужно, чтобы Петя не выигрывал (S ≥ 60), но после любого его хода Ваня выигрывал (S' ≤ 59).

    Все три хода Пети должны давать ≤ 59:

    • S − 2 ≤ 59 → S ≤ 61
    • S − 5 ≤ 59 → S ≤ 64
    • ⌊S/3⌋ ≤ 59 → S ≤ 179

    Самое строгое: S ≤ 61. Вместе с S ≥ 60 — кандидаты 60 и 61. Минимальное — 60.

    Ответ

    Минимальное S = 60

    Код¶

    def f(s, k):
    if s <= 19:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s-2, k-1), f(s-5, k-1), f(s//3, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return all(m)
print(*[s for s in range(20, 1000) if f(s, 2)])

    Пример 2 — основная волна 2025¶

    Условие: Можно убрать 3, убрать 6 или поделить на 3 (с округлением до меньшего). Кто первый сделал кучу ≤ 25 — победил. S > 25.

    Внимание

    В условии S > 25, а не S ≥ 25. Поэтому цикл начинается с 26, а не с 25.

    def f(s, k):
    if s <= 25:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s-3, k-1), f(s-6, k-1), f(s//3, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return all(m)
print(*[s for s in range(26, 1000) if f(s, 2)])

    Две кучи¶

    В чём особенность¶

    Если в задании две кучи, логика та же, только теперь два числа вместо одного:

    • Ходов больше: для каждой кучи свои операции. Обычно 4 варианта хода.
    • Победа по сумме: игра заканчивается, когда сумма камней достигает порога.
    • Одна куча часто зафиксирована: «в первой куче 13 камней, во второй — S». Сводит задачу к одномерной.

    Пример 1¶

    Условие: В первой куче 13 камней, во второй S (1 ≤ S ≤ 103). За ход можно добавить 1 в любую кучу или умножить любую на 2. Победа при сумме ≥ 117. Найти минимальное S, при котором Петя не выигрывает за 1 ход, но Ваня выигрывает своим первым ходом после неудачного хода Пети.

    def f(s1, s2, k):
    if s1 + s2 >= 117:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s1+1, s2, k-1), f(s1*2, s2, k-1),
         f(s1, s2+1, k-1), f(s1, s2*2, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return any(m)
print(*[s for s in range(13, 104) if f(s, 13, 2)])

    Пример 2¶

    Условие: В первой куче 15 камней, во второй S (1 ≤ S ≤ 300). За ход можно добавить 7 в любую кучу или умножить любую на 2. Победа при сумме ≥ 316. Найти максимальное S, при котором Петя не может выиграть за один ход, но при любом ходе Пети Ваня выигрывает своим первым ходом.

    def f(s1, s2, k):
    if s1 + s2 >= 316:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s1+7, s2, k-1), f(s1*2, s2, k-1),
         f(s1, s2+7, k-1), f(s1, s2*2, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return all(m)
print(*[s for s in range(15, 301) if f(s, 15, 2)])

    Ответ

    150

    Задание 20¶

    Задание 20 отличается от 19 всего одной строкой в конце — в код для 19 достаточно добавить проверку на второй ход.

    Главное отличие

    В 20-м задании Петя не выигрывает сразу, но у него есть стратегия, позволяющая гарантированно выиграть своим вторым ходом — независимо от того, как сходит Ваня.

    Что это значит¶

    1. Петя делает первый ход (и не побеждает).
    2. Ваня делает свой ход (может сходить по-разному).
    3. Петя делает второй ход и в любом случае побеждает.

    Пример 1 — одна куча¶

    Добавляем в конец кода для 19 задания строку:

    print(*[s for s in range(1, 313) if not f(s, 1) and f(s, 3)])
# Петя не выигрывает за первый ход, но побеждает своим вторым

    В ответе требуют наименьшее и наибольшее значения S — ответ 100 102. Но обычно спрашивают минимальное или два минимальных. Читайте, что от вас требуют.

    Пример 2 — две кучи¶

    print(*[s for s in range(1, 94) if not f(s, 13, 1) and f(s, 13, 3)])

    Задание 21¶

    В 20-м задании Петя выигрывал вторым ходом, в 21-м — ситуация зеркальная: Ваня имеет стратегию, чтобы выиграть первым или вторым ходом, но не может гарантированно выиграть сразу.

    Что это значит¶

    1. Петя делает первый ход.
    2. Если Петя ошибается — Ваня сразу выигрывает (первым ходом).
    3. Если Петя играет хорошо — Ваня всё равно выигрывает, но вторым ходом.

    То есть у Вани есть «подушка безопасности»: не получилось выиграть сразу — добьёт следующим ходом.

    Пример¶

    Добавляем в конец кода строку:

    print(*[s for s in range(1, 206) if not f(s, 17, 2) and f(s, 17, 4)])

    Здесь Ваня ходит по чётным ходам, поэтому изменились только цифры 2 и 4 после 17.

    Ответ

    S = 93
