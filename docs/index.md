# Гайды для ЕГЭ по информатике 2027

Гайд создан **для личного пользования** - для повторения информации, необходимой для сдачи ЕГЭ по информатике.

!!! quote "О гайде"
    - Гайд **не является учебным материалом** и не создан с целью кого-то научить.
    - Материал собран **на основе собственных знаний** и информации, найденной в открытых источниках.
    - Структура и примеры - результат **личной подготовки** к экзамену.
    - Публикация на GitHub Pages - **только для удобного просмотра с любого своего устройства**.

## Содержание

- **[Задание 1 - Схема дорог](task-1.md)** - графы, таблицы, матрица смежности
- **[Задание 8 - Перебор слов](task-8.md)** - `itertools.product`, системы счисления, лексикографический порядок
- **[Задание 19–21 - Теория игр](task-19-21.md)** - типы формулировок, определения, логика, код
