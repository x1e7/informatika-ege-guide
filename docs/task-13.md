# Задание 13: Количество программ исполнителя

## Что стоит знать перед выполнением

**Команда** - некое правило, которое превращает текущее число x в новое число, например:

- «прибавь k
- «умножь на k;
- «раздели нацело на k.

**Программа** - последовательность данных правил (команд).

**Траектория вычислений** - последовательность результатов выполнения каждой команды программы. **Стартовое число** в траекторию не входит, а последнее число траектории - это результат работы всей программы.

**Пример:** 
Команды: 
- 1: прибавить 6
- 2: умножить на 4
- 3: прибавить 7

Программа: 132  

Исходное число: 3
Траектория: 9, 16, 64 (3 + 6 = 9, 9 + 7 = 16, 16 * 4 = 64).

Если сказано, что траектория содержит число **n** значит: где-то в этой последовательности результатов есть **n**, причём **n** может совпадать и с **конечным числом** - оно тоже часть траектории.

## Задача 1

!!! quote "Источник"
    **ФИПИ** · уровень: средний

Исполнитель Кантата преобразует число на экране.

У исполнителя есть три команды, которым присвоены номера:

Прибавить 1.
Умножить на 2.
Умножить на 3.
Первая команда увеличивает число на экране на 1, вторая умножает его на 2, третья умножает его на 3. Программа для исполнителя Кантата - это последовательность команд.

Сколько существует программ, для которых при исходном числе 5 результатом является число 43 и при этом траектория вычислений содержит число 9, но не содержит число 27?

Траектория вычислений программы - это последовательность результатов выполнения всех команд программы. Например, для программы 123 при исходном числе 7 траектория будет состоять из чисел 8, 16, 48.

### Решение

```python
from functools import lru_cache

@lru_cache(None)
def f(n, target, bad=()):
    if n in bad or n > target:
        return 0
    if n == target:
        return 1
    return f(n + 1, target, bad) + f(n * 2, target, bad) + f(n * 3, target, bad)

print(f(5, 9) * f(9, 43, (27,)))
```

**Что делает код:**

- `@lru_cache` - декоратор, который запоминает результаты вызовов функции, чтобы не считать одно и то же дважды.
- `def f(n, target, bad=()):` - объявляем функцию: `n` - исходное число, `target` - конечное, `bad` - кортеж чисел, которые траектория не должна содержать.
- `if n in bad or n > target` - если число в списке «исключённых» или больше конечного, возвращаем 0: такой программы нет.
- `if n == target` - если `n` равно конечному числу, возвращаем 1: программа дошла до цели.
- `return f(n + 1, target, bad) + f(n * 2, target, bad) + f(n * 3, target, bad)` - пробуем **все три команды по очереди** и складываем количество программ для каждой:
    - `f(n + 1, target, bad)` - сколько программ из `n + 1` в цель (команда «прибавить 1»);
    - `f(n * 2, target, bad)` - сколько программ из `n * 2` в цель (команда «умножить на 2»);
    - `f(n * 3, target, bad)` - сколько программ из `n * 3` в цель (команда «умножить на 3»).

    Команды **взаимоисключающие** (первой может быть только одна из трёх), поэтому общее число программ = **сумма**, а не произведение.

**Про финальную строку:**

- `print(f(5, 9) * f(9, 43, (27,)))` - ищем, сколько программ ведут из 5 в 9, и умножаем на количество программ из 9 в 43. **Произведение**, потому что после того, как дошли до 9, дальше идёт **независимая** программа.
- `(27,)` - это **кортеж** из одного элемента. Запятая обязательна: без неё `(27)` - просто число в скобках, а не кортеж, но функция ожидает кортеж.
- `(27,)` передаётся **только во второй вызов** `f(9, 43, ...)`, потому что именно участок **от 9 до 43** не должен содержать 27. На участке 5 → 9 ограничение не действует, ведь числа 27 там быть не может.

!!! success "Ответ"
    **19**

## Задача 2

!!! quote "Источник"
    **Профиматика** · уровень: сложный

Исполнитель преобразует число, записанное на экране. У исполнителя есть четыре команды которые обозначены латинскими буквами:

A. Прибавить 1
B. Прибавить 2
С. Прибавить 4
D. Прибавить 8

Программа исполнителя — это последовательность команд.

Сколько существует программ, для которых при исходном числе 16 результатом является число 48, если никакую из команд нельзя повторять дважды подряд?

### Решение

```python
from functools import lru_cache

@lru_cache(None)
def f(n, target, last=None):
    if n > target:
        return 0
    if n == target:
        return 1
    total = 0
    for add, cmd in ((1, 'A'), (2, 'B'), (4, 'C'), (8, 'D')): # (сколько добавить, номер команды)
        if cmd == last:      # нельзя повторять ту же команду подряд, поэтому если текущая команда равна последней - переходим к следующей
            continue
        total += f(n + add, target, cmd)
    return total

print(f(16, 48))
```

**Что делает код:**

Всё тоже самое, что и в **Задаче 1**, но так как в условии не сказано ничего о числах, которые нужно исключить из траектории - убираем кортеж bad.
Но вместо него добавляем - last, который хранит последнюю команду. ('A', 'B', 'C', 'D'). По умолчанию None - значит, это первый ход.

!!! success "Ответ"
    **41993**
