# Рекомендации

## Запуст IDLE Python

### 1. Найти Python в поиске

Скачиваем и устанавливаем Python с [официального сайта](https://www.python.org/).

### 2. Открыть IDLE

В левом верхнем углу нажимаем **File** → **New File** (или **Open**).

### 3. Сохранить файл

Все файлы следует держать в одном месте для удобной работы.

!!! tip "Совет"
    В IDLE можно запустить код через **F5** (Run Module). Перед запуском нужно сохранять файл.

!!! success "Удачи!"
    Главное — понять логику 19-го задания. Дальше 20 и 21 решаются почти автоматически.
