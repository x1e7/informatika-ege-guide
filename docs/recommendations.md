# Рекомендации

## Запуск IDLE Python

Скачиваем и устанавливаем Python с [официального сайта](https://www.python.org/){ target="_blank" }.
Находим IDLE, открываем его.
В левом верхнем углу нажимаем **File** → **New File** (или **Open**).
Сохраняем созданный файл. (Все файлы следует держать в одном месте для удобной работы.)

!!! tip "Совет"
    В IDLE можно запустить код через **F5** (Run Module). Перед запуском нужно обязательно сохранять файл.
