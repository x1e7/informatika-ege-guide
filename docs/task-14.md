## Задача 1 — Демо 2027

!!! quote "Источник"
    **Демо 2027**

**Условие.** Операторы арифметического выражения записаны в системе счисления с основанием 22:

```
27x98876₂₂ + 26x51₂₂ + 711x5₂₂
```

В записи чисел переменной `x` обозначена неизвестная цифра из алфавита 22-ричной системы счисления. Определите **наименьшее** значение `x`, при котором значение данного арифметического выражения кратно 21. Для найденного `x` вычислите частное от деления значения арифметического выражения на 21 и укажите его в ответе в десятичной системе счисления. Основание системы счисления указывать не нужно.

### Решение

```python
alphabet = '0123456789abcdefghijklmnopqrstuvwxyz'[:22]

for x in alphabet:
    n = int(f'27{x}98876', 22) + int(f'26{x}51', 22) + int(f'711{x}5', 22)

    if n % 21 == 0:
        print(n // 21)

```

!!! success "Ответ"
    **276296118**

## Задача 2 — Демо 2027

!!! quote "Источник"
    **Демо 2027**

**Условие.** Значение арифметического выражения

```
3 · 3125⁸ + 2 · 625⁷ − 4 · 625⁶ + 3 · 125⁵ − 2 · 25⁴ − 2025
```

записали в системе счисления с основанием 25. Сколько **значащих нулей** содержится в этой записи?

### Решение

```python
N = 3*3125**8 + 2*625**7 - 4*625**6 + 3*125**5 - 2*25**4 - 2025

base25 = ""
while N > 0:
    base25 = str(N % 25) + base25
    N //= 25
    
print(base25)
print(base25.count('0'))
```

!!! success "Ответ"
    **10**

## Задача 3 — Демо 2027

!!! quote "Источник"
    **Демо 2027**

**Условие.** Значение арифметического выражения

```
7¹⁷⁰ + 7¹⁰⁰ − x
```

где `x` — целое положительное число, не превышающее 2030, записали в 7-ричной системе счисления. Определите **наибольшее** значение `x`, при котором в данной записи значения арифметического выражения содержится ровно 71 ноль. В ответе запишите число в десятичной системе счисления.

### Решение

```python
for x in range(2030, -1, -1):
    N = 7**170 + 7**100 - x
    
    base7 = ""
    while N > 0:
        base7 = str(N % 7) + base7
        N //= 7
    
    if base7.count('0') == 71:
        print(x)
        break
```

!!! success "Ответ"
    **2029**
