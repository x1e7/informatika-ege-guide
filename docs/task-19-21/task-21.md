# Задание 21

В 20-м задании Петя выигрывал вторым ходом, в 21-м — ситуация зеркальная: **Ваня** имеет стратегию, чтобы выиграть первым или вторым ходом, но не может гарантированно выиграть сразу.

## Что это значит

1. Петя делает первый ход.
2. Если Петя ошибается — Ваня **сразу** выигрывает (первым ходом).
3. Если Петя играет хорошо — Ваня всё равно выигрывает, но **вторым ходом**.

То есть у Вани есть «подушка безопасности»: не получилось выиграть сразу — добьёт следующим ходом.

## Пример

Добавляем в конец кода строку:

```python
print(*[s for s in range(1, 206) if not f(s, 17, 2) and f(s, 17, 4)])
```

Здесь Ваня ходит по чётным ходам, поэтому изменились только цифры 2 и 4 после 17.

!!! success "Ответ"
    **S = 93**
