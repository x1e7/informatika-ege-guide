# Задание 19: Две кучи

## В чём особенность

Если в задании две кучи, логика та же, только теперь **два числа** вместо одного:

- **Ходов больше:** для каждой кучи свои операции. Обычно 4 варианта хода.
- **Победа по сумме:** игра заканчивается, когда *сумма* камней в обеих кучах достигает порога.
- **Одна куча часто зафиксирована:** «в первой куче 13 камней, во второй — S». Это сводит задачу к одномерной.

## Пример 1

**Условие:** В первой куче 13 камней, во второй S (1 ≤ S ≤ 103). За ход можно добавить 1 в любую кучу или умножить любую на 2. Победа при сумме ≥ 117. Найти минимальное S, при котором Петя не выигрывает за 1 ход, но Ваня выигрывает своим первым ходом после **неудачного** хода Пети.

```python
def f(s1, s2, k):
    if s1 + s2 >= 117:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s1+1, s2, k-1), f(s1*2, s2, k-1),
         f(s1, s2+1, k-1), f(s1, s2*2, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return any(m)
print(*[s for s in range(13, 104) if f(s, 13, 2)])
```

## Пример 2

**Условие:** В первой куче 15 камней, во второй S (1 ≤ S ≤ 300). За ход можно добавить 7 в любую кучу или умножить любую на 2. Победа при сумме ≥ 316. Найти **максимальное** S, при котором Петя не может выиграть за один ход, но при любом ходе Пети Ваня выигрывает своим первым ходом.

```python
def f(s1, s2, k):
    if s1 + s2 >= 316:
        return k % 2 == 0
    if k == 0:
        return 0
    m = [f(s1+7, s2, k-1), f(s1*2, s2, k-1),
         f(s1, s2+7, k-1), f(s1, s2*2, k-1)]
    if (k-1) % 2 == 0:
        return any(m)
    return all(m)
print(*[s for s in range(15, 301) if f(s, 15, 2)])
```

!!! success "Ответ"
    **150**
